    Class 8.2 - 基于模型的推断¶

    1. 基于模型推断的核心思路¶

    基于模型的推断（Model-Based Inference）是因果推断的第一大策略：

    • 核心思路：利用领域知识，对数据的生成过程作出假设，通过统计建模的方式"控制"那些同时影响处理变量和结果变量的混淆因素，从而近似还原出"其他条件不变"的对比
    • 优点：不需要专门设计实验，可以直接利用已有的观测数据
    • 局限：结论依赖于假设的正确性；若存在未观测到的混淆变量，模型无法发现，结论可能系统性偏差

    2. 模型推断模拟案例¶

    为了直观理解混淆变量的问题，我们来看一个经典的模拟案例的场景设定：

    • 有棕色头发的人比其他发色的人收入更高，真实效应为 +0.1 的对数收入提升 - 背后的道理其实是有钱染发说明了一个人的经济能力
    • 有大学学历的人比没有大学学历的人收入更高，真实效应为 +0.2 的对数收入提升
    • 20% 的人天生拥有棕色头发，与学历无关
    • 30% 的人拥有大学学历
    • 关键：在无大学学历的人中，有更高比例会选择染棕色头发；有大学学历的人不染发

    现在，如果一个分析师不知道学历的存在，只是简单对比 hair == "Brown" 和 hair == "Other Color" 两组的平均收入，他会得出什么结论？

    (1) 模拟数据生成¶

    首先导入所需的包，并生成模拟数据：

    library(tidyverse)
set.seed(42)

sim <- 
  tibble(
    # college: 总样本5000人，其中约30%上过大学
    # 对于每个样本，我们随机生成一个0-1之间的数，如果小于0.3就认为这个人上过大学
    college = runif(5000) < 0.3
  ) |>
  mutate(
    # hair: 根据是否上过大学和随机因素决定发色
    # 对于每个样本，我们随机生成一个0-1之间的数，如果小于0.2+0.8*0.4*(!college)就认为这个人的发色是棕色
    # 也就是说，如果没上过大学，那么有更高的概率是棕色，概率是0.2+0.8*0.4*1=0.52，那么有48%的概率是其他颜色
    # 如果上过大学，那么有更低的概率是棕色，概率是0.2+0.8*0.4*0=0.2，那么有80%的概率是其他颜色
    hair = case_when(
      runif(5000) < 0.2+0.8*0.4*(!college) ~ "Brown",
      TRUE ~ "Other Color" # 相当于 .default ~ "Other Color"
    ),
    # log_income: 根据发色和是否上过大学以及随机因素决定收入
    # 基础输入是 N(5, 1) 分布上的随机数
    # 如果发色是棕色，那么收入会在此基础上增加0.1；如果上过大学，那么收入会在此基础上增加0.2
    log_income = 0.1*(hair == "Brown") + 0.2*college + rnorm(5000) + 5 
)

sim |> slice_head(n = 10)

    | college <lgl> | hair <chr>  | log_income <dbl> |
|---------------|-------------|------------------|
| FALSE         | Other Color | 5.071222         |
| FALSE         | Other Color | 5.970290         |
| TRUE          | Other Color | 5.510035         |
| FALSE         | Other Color | 4.860451         |
| FALSE         | Brown       | 4.773689         |
| FALSE         | Brown       | 4.981190         |
| FALSE         | Other Color | 5.893559         |
| TRUE          | Other Color | 5.411115         |
| FALSE         | Other Color | 4.511220         |
| FALSE         | Brown       | 4.879628         |

    数据说明：

    • college：是否有大学学历（TRUE/FALSE），30% 的概率为 TRUE

    • hair：头发颜色，"Brown" 或 "Other Color"。概率规则由 runif(5000) < 0.2+0.8*0.4*(!college) 控制：

      • 有学历者（college == TRUE）：P(Brown) = 0.2，即只有天生棕发的概率
      • 无学历者（college == FALSE）：P(Brown) = 0.2 + 0.8 × 0.4 = 0.52，包含染发概率

    • log_income：对数收入，棕发真实效应为 +0.1，大学学历效应为 +0.2，加上正态随机误差

    因果分析目的：

    • 我们想要把棕色头发的对收入的效应从数据中提取出来
    • 也就是这个模拟数据中的 +0.1，通过分析数据还原出来

    (2) 直接对比¶

    我们首先可以想到的一个简单方法是：直接比较两组的平均收入：

    • 我们可以通过作图的方式，观察两组的收入分布：
    sim |>
  ggplot(aes(x = log_income, fill = hair)) +
  geom_density(alpha = 0.4) +
  ggokabeito::scale_fill_okabe_ito() + 
  labs(
    x = "Income",
    y = "Density",
    fill = "Hair color",
    title = "Income distributions by hair color"
  ) +
  theme_minimal()
    • 也可以通过计算两组的平均收入来量化差异：
    sim |> 
  group_by(hair) |> 
  summarise(mean_income = mean(log_income)) |> 
  mutate(pct_diff = round(mean_income - lag(mean_income), 2))

    | hair <chr>  | mean_income <dbl> | pct_diff <dbl> |
|-------------|-------------------|----------------|
| Brown       | 5.085040          | NA             |
| Other Color | 5.102476          | 0.02           |

    不论是图中还是我们计算的统计量：

    • 我们会发现，朴素对比估计出的收入差距，远小于真实的 0.1
    • 也就是说直接对比的方式严重低估了棕色头发的真实效应

    问题的根源在于大学学历是一个混淆变量（Confounding Variable）：

    • 学历会同时影响 hair 和 log_income：

      • 学历同时影响了 hair - 有学历的人不染发，导致 "Brown" 组中无学历者比例更高
      • 学历也同时影响了 log_income - 有学历的人收入更高

    • 因此，学历这个混淆变量导致了两组之间的系统性差异：

      • "Brown" 组因为混入了大量无学历低收入者，mean_income 被拉低
      • "Other Color" 组中有学历高收入者比例更高，mean_income 被拉高
      • 两组之间的真实差距因此被低估了

    这就是遗漏变量偏差（Omitted Variable Bias）：

    • 忽略了一个与处理变量和结果变量都相关的变量
    • 导致估计结果产生系统性偏差

    (3) 控制混淆变量¶

    控制混淆变量的一个方法是：

    • 不能全样本比较，而是要分组比较
    • 如果我们知道学历是混淆变量，可以只在 college == TRUE 的人中比较两组的 log_income 差异
    • 原因：有学历者不染发，因此在有学历人群中，hair 的取值完全由天生决定，与学历无关，两组唯一的系统性差异就是头发颜色本身

    我们直接在有学历的人中比较两组的平均收入：

    sim |> 
  filter(college == TRUE) |> 
  group_by(hair) |>
  summarise(mean_income = mean(log_income)) |> 
  mutate(pct_diff = round(mean_income - lag(mean_income), 3))

    | hair <chr>  | mean_income <dbl> | pct_diff <dbl> |
|-------------|-------------------|----------------|
| Brown       | 5.325553          | NA             |
| Other Color | 5.203452          | -0.122         |
    • 从结果中可以看到：控制学历后，pct_diff 接近真实的 0.1
    • 控制混淆变量后，模型推断成功还原了因果效应

    3. 基于模型推断的局限性¶

    从上面的案例可以看到，基于模型的推断在以下条件下有效：

    • 分析师知道哪些是混淆变量
    • 这些混淆变量可以被观测到（数据中有记录）
    • 对数据生成过程的假设是正确的

    但这些条件在现实中往往难以满足：

    • 未观测到的混淆变量：若存在其他同时影响处理和结果的变量，但数据中没有记录，模型就无能为力
    • 假设不可验证：对数据生成过程的假设是否正确，通常无法从数据本身加以证伪
    • 错误的模型结构：即使所有变量都已观测，若对变量关系的函数形式假设有误，结论仍可能偏差

    一旦存在未被控制的混淆变量，基于模型的推断会悄无声息地产生错误结论：

    • 而且更严重的是，分析者可能根本不知道问题的存在
    • 这就引出了因果推断的第二大策略，基于设计的推断，它试图从根本上绕过混淆变量问题，而不是依赖假设去控制它们
