    Class 7 - 数据分析 - 描述性分析¶

    本章我们正式进入数据分析阶段，先来学习描述性分析方法，这一部分的重点是如何将数据进行分群，来更好地理解数据中的模式和结构。

    • Class 7.1 - 描述性分析的概念：介绍描述性分析的基本概念和意义，为什么分群分析是描述性分析中的重要方法，以及我们将要使用的案例数据。
    • Class 7.2 - 基于规则的分群方法 - RFM 分群：介绍 RFM 分群的基本概念、计算方法以及如何应用于客户分群。
    • Class 7.3 - 基于数据的分群方法 - K-Means 分群：介绍 K-Means 聚类的基本原理、算法步骤以及如何在实际数据中应用。
