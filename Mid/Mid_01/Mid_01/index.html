    Mid-Exam Question Set 01¶

    Introduction. Working with Product Review data.¶

    Imagine you are a business analyst working in Amazon's Pet Supplies team. You have been given a dataset of customer reviews for pet products sold on Amazon. Your task is to use these data to understand customer feedback, identify patterns in product reviews, and support business decisions based on the information available.

    The dataset includes the following variables:

    • customer_id : unique ID for the customer who wrote the review
    • product_id : unique ID for the product being reviewed
    • product_title : name of the product
    • star_rating : star score given by the customer, from 1 to 5
    • helpful_votes : number of users who marked the review as helpful
    • review_date : date the review was submitted

    Part A. Understanding the business question and the data¶

    Before diving into analysis, it is important to understand what this dataset contains, what kinds of questions it can answer, and how to inspect it in R.

    Q1¶

    Question:

    Which of the following business questions could be answered directly using this dataset alone?

    Options:

    • A. Which pet products received the most reviews?
    • B. Whether customers who bought dog products later switched to cat products
    • C. Whether higher-rated pet products sold more units
    • D. Whether a 0.5-star increase in rating causes higher sales

    Answer: A

    Q2¶

    Question:

    The data are stored in the data directory of a posit cloud workspace in a file called "pet_supplies.csv". Which line of code would correctly read the dataset into R and store it in an object called pet_supplies?

    Options:

    • A. pet_supplies <- read_csv("pet_supplies.csv")
    • B. pet_supplies <- read_csv("data/pet_supplies.csv")
    • C. pet_supplies <- read_csv(data/"pet_supplies.csv")
    • D. pet_supplies <- read_csv("data_pet_supplies.csv")

    Answer: B

    Q3¶

    Question:

    Which two functions would directly return the number of rows and the number of columns in pet_supplies?

    Options:

    • A. nrow() and ncol()
    • B. rows() and cols()
    • C. count_rows() and count_columns()
    • D. glimpse() and names()

    Answer: A

    Q4¶

    Question:

    A small preview of the dataset is shown below.

    customer_id product_id product_title star_rating review_date
    1001 B001E4KFG0 Dog Chew Toy 5 2015-01-03
    1001 B009PLS8KQ Cat Litter Mat 4 2015-02-11
    8845 B001E4KFG0 Dog Chew Toy 3 2015-03-20
    7712 B004A7X27A Bird Seed Mix 5 2015-03-20
    5520 B00HZX9OQY Pet Shampoo 2 2015-01-03

    Based on this preview, what does each row in the dataset most likely represent?

    Options:

    • A. A review of a pet product written by a customer
    • B. All reviews posted on a given date
    • C. A single pet product
    • D. A single customer

    Answer: A

    Part B: Transforming the Data with dplyr¶

    In this section, you will work with the pet_supplies review dataset to answer business questions using data transformation tools from dplyr.

    Q5¶

    Question:

    You want to keep only the variables needed to study which products received the highest ratings and when those reviews were posted. Which code does this correctly?

    Options:

    • A. pet_supplies |> select(product_id, product_title, star_rating, review_date)
    • B. pet_supplies |> summarise(product_id, product_title, star_rating, review_date)
    • C. pet_supplies |> distinct(product_id, product_title, star_rating, review_date)
    • D. pet_supplies |> filter(product_id, product_title, star_rating, review_date)

    Answer: A

    Q6¶

    Question:

    You want a single-number summary showing how many different customers appear in pet_supplies. Which code best does this?

    Options:

    • A. pet_supplies |> summarise(n_customers = n())
    • B. pet_supplies |> distinct(customer_id)
    • C. pet_supplies |> summarise(n_customers = n_distinct(customer_id))
    • D. pet_supplies |> select(customer_id)

    Answer: C

    Q7¶

    Question:

    Suppose an analyst writes the following code:

    pet_supplies |>
  group_by(star_rating) |>
  summarise(n = n())

    What does the resulting table contain?

    Options:

    • A. One row for each star rating, with the number of reviews in each rating category
    • B. One row for each customer, with the number of ratings they gave
    • C. One row for each review date, with the average star rating on that date
    • D. One row for each product, with its average star rating

    Answer: A

    Q8¶

    Question:

    An analyst has already created the following summary table:

    rating_summary <- pet_supplies |>
  group_by(star_rating) |>
  summarise(n = n())

    They now want to add a new column showing the percentage of all reviews in each star-rating category. Which line of code would do this correctly?

    Options:

    • A. rating_summary |> mutate(pct = 100 * n / sum(n))
    • B. rating_summary |> summarise(pct = 100 * n / sum(n))
    • C. rating_summary |> mutate(pct = 100 * n / n)
    • D. rating_summary |> summarise(pct = 100 * n / n)

    Answer: A

    Q9¶

    Question:

    You want to produce a table showing the products with the largest number of reviews at the top. Which code does this correctly?

    Options:

    • A. pet_supplies |> group_by(product_id) |> summarise(n = n()) |> arrange(n)
    • B. pet_supplies |> arrange(desc(product_id)) |> summarise(n = n())
    • C. pet_supplies |> summarise(n = n(product_id)) |> arrange(desc(n))
    • D. pet_supplies |> group_by(product_id) |> summarise(n = n()) |> arrange(desc(n))

    Answer: D

    Q10¶

    Question:

    You want to count the number of reviews for each combination of product and star rating. Which code does this correctly?

    Options:

    • A. pet_supplies |> group_by(product_id) |> summarise(n = n(star_rating))
    • B. pet_supplies |> group_by(product_id, star_rating) |> summarise(n = n())
    • C. pet_supplies |> group_by(star_rating) |> summarise(n = n())
    • D. pet_supplies |> group_by(product_id, star_rating) |> summarise(n = count())

    Answer: B

    Q11¶

    Question:

    You want to keep only reviews that received at least one helpful vote. Which code does this correctly?

    Options:

    • A. pet_supplies |> filter(helpful_votes >= 1)
    • B. pet_supplies |> mutate(helpful_votes >= 1)
    • C. pet_supplies |> filter(helpful_votes > 1)
    • D. pet_supplies |> mutate(helpful_votes > 1)

    Answer: A

    Part C: Data Visualisation with ggplot2¶

    In this section, you will think about how to visualise patterns in the pet_supplies review data.

    Q12¶

    Question:

    In ggplot2, what is the main purpose of aes()?

    Options:

    • A. It renames variables so they display differently in the plot
    • B. It maps variables in the dataset to visual properties of the plot, such as axes, colour, or fill
    • C. It chooses the type of graph to draw, such as a bar chart or histogram
    • D. It adds labels and titles to the plot

    Answer: B

    Q13¶

    Question:

    You want to show how many reviews fall into each star-rating category. Which plot is the most appropriate?

    Options:

    • A. A histogram of star_rating, split into separate panels for each month
    • B. A bar chart showing the count of reviews for each value of star_rating
    • C. A bar chart showing the average star_rating for each product_id
    • D. A line chart showing average star_rating over time

    Answer: B

    Q14¶

    Question:

    Fill in the blanks. Complete the code below to plot how many reviews fall into each star-rating category.

    pet_supplies |>
  ggplot(aes(x = ___(i)___)) +
  ___(ii)___()

    Which pair correctly completes the code?

    Options:

    • A. (i) star_rating ; (ii) geom_bar
    • B. (i) product_id ; (ii) geom_bar
    • C. (i) star_rating ; (ii) geom_histogram
    • D. (i) star_rating, y = star_rating ; (ii) geom_bar

    Answer: A

    Q15¶

    Question:

    An analyst writes the following code to study average star ratings over time:

    pet_supplies |>
  group_by(review_date) |>
  summarise(
    avg_rating = mean(star_rating),
    n_reviews = n()
  ) |>
  ggplot(aes(x = review_date, y = n_reviews)) +
  geom_point()

    What is the main problem with this code?

    Options:

    • A. It should use filter() before summarise()
    • B. It should group by product_id instead of review_date
    • C. It should use geom_bar() instead of geom_point()
    • D. It plots the number of reviews by date, not the average star rating by date

    Answer: D

    Q16¶

    Question:

    Before merging the review data with sales_weekly, you want to create a review summary at the same level of detail as the sales data. Which summary is the best choice?

    Options:

    • A. Average star_rating for each product_id and week
    • B. Average star_rating across the whole dataset
    • C. Number of reviews for each review_date
    • D. Average star_rating for each customer_id

    Answer: A

    Q17¶

    Question:

    A colleague now gives you a dataset called review_weekly that contains, for each product_id and week, an average star rating, rating. You want to keep all rows in sales_weekly and add matching review information where available. Which function does this correctly?

    Options:

    • A. left_match()
    • B. left_join()
    • C. join()
    • D. pivot_wider()

    Answer: B

    Part D: Extending the Analysis by Merging Review Data with Sales¶

    In practice, analysts often combine multiple datasets to answer broader business questions. Suppose you are also given a second dataset called sales_weekly, where each row contains weekly sales for a product.

    The dataset includes the following variables:

    • product_id : unique ID for the product
    • week : the week of the sale
    • units_sold : number of units sold in that week

    You want to combine this dataset with the review data to study whether higher-rated products also tend to sell more.

    Q18¶

    Question:

    A colleague now gives you a dataset called review_weekly that contains, for each product_id and week, an average star rating, rating. You want to keep all rows in sales_weekly and add matching review information where available. Which code correctly specifies the matching columns?

    Options:

    • A. join_by(product_id, week, rating)
    • B. join_by(product_id, week)
    • C. join_by(product_id, rating)
    • D. join_by(product_id)

    Answer: B

    Q19¶

    Question:

    The table below shows average weekly sales for products in different average-rating bands.

    Average rating band Average weekly sales
    2.0–2.5 110
    2.5–3.0 132
    3.0–3.5 145
    3.5–4.0 160
    4.0–4.5 176
    4.5–5.0 180

    Which statement is best supported by the table?

    Options:

    • A. Increasing a product from the 3.5–4.0 band to the 4.0–4.5 band leads to the largest percentage increase in weekly sales
    • B. Products in higher rating bands tend to have higher average weekly sales, but the percentage increase is not the same at every half-star step
    • C. The percentage increase in sales is about the same at every half-star step
    • D. The percentage increase in sales is largest between the 2.5–3.0 and 3.0–3.5 bands

    Answer: B

    Part E: Interpreting Results¶

    Q20¶

    Question:

    Suppose a manager asks whether a brand should invest in trying to improve product ratings. In 2–4 sentences, explain one reason to be cautious about making that decision based only on the table, and explain one sensible next analytical step before acting.

    Answer: One reason to be cautious is that the table only shows an association between average rating bands and average weekly sales, but it does not establish causation. It is possible that higher-rated products have other characteristics (e.g., better marketing, more features) that drive sales, rather than the ratings themselves causing higher sales. A sensible next analytical step would be to conduct a more detailed analysis, such as a regression analysis controlling for other product features, or even an experiment where some products are improved in rating while others are not, to better understand the causal relationship between ratings and sales.
