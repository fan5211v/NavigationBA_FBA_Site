    Topic 10.2 - 数据存储：电子表格与平面文件¶

    1. 电子表格¶

    (1) 电子表格简介¶

    对很多人来说，Microsoft Excel 或 Google Sheets 等电子表格是进入商业分析之前默认的数据处理方式

    • 事实上，对于不接触代码和 IT 工具的人来说，电子表格是一个非常强大的工具，提供了一个友好的界面来组织表格、应用公式和制作快速图表
    • 虽然我们目前和之后都会学习比 Excel 更强大的工具，但是依然改变不了 Excel 是一种广泛接受、老少皆宜的工具的事实
    • 并且 Excel 是快速探索和轻量级协作的强大工具，适合小团队、早期原型设计

    但当工作转向可重复性、可扩展性或自动化时，Excel 的局限性就会暴露出来：

    • 无法记录步骤：无法始终追溯某个数字或图表是如何计算出来的
    • 无内置版本历史：公式往往在单元格之间隐形地变化
    • 容易出错：一个引用错误列的单元格可能扭曲整个分析，且难以察觉
    • 继承问题：如果从他人那里继承电子表格，这些文件可能包含问题，例如，不一致的命名规、手动合计、隐藏的格式或注释、合并的单元格、跨标签重复的值等

    (2) 在 R 中读写 Excel 文件¶

    R 中默认是无法直接处理 Excel 文件的，但有一些包可以帮助我们读写 Excel 文件：

    • 读取 Excel 文件：readxl 包中的 read_excel() 函数
    • 写出 Excel 文件：writexl 包中的 write_xlsx() 函数

    我们本节使用的 Excel 文件是 ebay_auctions.xlsx，它当中有三个工作表：

    1. auctions：包含每次拍卖的信息
    2. bids：包含每次拍卖的出价信息
    3. sellers：包含每件商品卖家的信息

    读取 Excel 文件时，工作表就会读取为一个 tibble：

    • 默认情况下，read_excel() 会读取第一个工作表
    library(tidyverse)
library(readxl)
library(writexl)

auctions_excel <- read_excel("ebay_auctions.xlsx")
    • 如果要指定读取特定的工作表，可以使用 sheet 参数：
    # 可以使用工作表名称
bids_excel <- read_excel("ebay_auctions.xlsx", sheet = "bids")

# 可以使用工作表序号
bids_excel <- read_excel("ebay_auctions.xlsx", sheet = 2)

    如果想要写入 Excel 文件，可以使用 write_xlsx() 函数：

    # 创建一个新的tibble，包含拍卖 AUC00001 的出价，用于写入 Excel 文件
bids_to_export <-
  bids_excel |> 
  filter(item_id == "AUC00001")

write_xlsx(bids_to_export, "small_bids.xlsx")

    2. 平面文件¶

    (1) 平面文件简介¶

    平面文件其实就是我们前半学期已经很熟悉的 CSV 文件了：

    • CSV 文件全称是 Comma-Separated Values，逗号分隔值，是一种以纯文本形式存储表格数据的格式
    • 每行代表一个观测，每列代表一个变量，列之间用逗号分隔，行之间用换行分隔
    • 没有公式，没有样式，没有隐藏或合并的单元格，只有原始信息
    • 并且与 Excel 不同，CSV 每个文件存储一个数据集，没有多个工作表的概念

    CSV 文件的优势在于：

    • 以纯文本的形式存储，具有极高的可移植性和兼容性，几乎所有的数据分析工具都支持 CSV 格式
    • 数据的结构和内容非常透明，易于手动检查和理解
    • 当我们需要可靠地存储和共享结构化数据，尤其是以代码可复现的方式时，CSV 文件往往是更好的选择

    与 CSV 文件类似的还有 TSV 文件（Tab-Separated Values，制表符分隔值）：

    • 它使用制表符（\t）作为列分隔符
    • 事实上与 CSV 文件的区别不大，只是分隔符不同，适合于数据中可能包含逗号的情况

    (2) 在 R 中读写平面文件¶

    在 R 中处理平面文件，通常是使用以下函数：

    • 读取 CSV 文件：readr 包中的 read_csv() 函数
    • 写入 CSV 文件：readr 包中的 write_csv() 函数
    • 但是 readr 包已经整合在 tidyverse 中了，所以我们直接使用 tidyverse 就可以了

    使用 read_csv() 读取 CSV 文件：

    bids_flat <- read_csv("bids.csv")

    使用 write_csv() 写入 CSV 文件：

    # 创建一个新的tibble，包含拍卖 AUC00001 的出价，用于写入 CSV 文件
auctions_filtered <-
  bids |> 
  filter(item_id == "AUC00001")

write_csv(auctions_filtered, "bids_auc0001.csv")
