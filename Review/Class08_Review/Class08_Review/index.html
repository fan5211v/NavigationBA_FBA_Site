    Class 8 知识点总结¶

    Class 8 主要内容是因果分析，这一章几乎没有需要背的代码，重点是掌握两种因果推断的方法：

    • 因果问题的核心概念以及潜在结果框架
    • 基于模型的推断的核心逻辑
    • 基于设计的推断的核心逻辑
    • 两种推断方法的核心区别

    1. 因果问题的核心概念¶

    (1) 因果问题的朴素对比的不可靠性¶

    因果问题问的是：如果我们做了某事之后，结果会怎样？

    • 例如，我们提出的问题是：上补习班是否会提高学生的数学成绩？

    • 一个比较直观的对比方法是朴素对比：

      • 可以直接比较接受处理和未接受处理的群体平均结果：就是对比上补习班和没上补习班的学生的平均成绩
      • 可以直接比较处理前和处理后的平均结果：对比同一组学生在上补习班前后的成绩

    • 这两种方式往往都不可靠，因为会受到混淆变量（confounder）的影响：同时影响处理和结果的因素

      • 如果是对比接受处理和未接受处理的群体平均结果，混淆变量会导致两组在其他方面不完全可比：例如家庭经济情况会同时影响是否上补习班和数学成绩
      • 如果是对比处理前和处理后的平均结果，其他时间变化的因素也会混入结果：例如处理后发生在第二学期，这时考试简单，而处理前发生在第一学期，考试较难

    • 因此，混淆变量让处理和结果之间出现并非因果的关联

    (2) 潜在结果框架¶

    在个体层面：对于每个个体 \(i\)：

    符号 含义
    \(Y_i(1)\) 个体 \(i\) 接受处理时的结果
    \(Y_i(0)\) 个体 \(i\) 不接受处理时的结果
    \(\tau_i = Y_i(1) - Y_i(0)\) 个体 \(i\) 的因果效应
    • 因果推断的根本问题是，同一个人在现实中只能处于一种状态，要么是接受处理，要么是不接受处理
    • 所以我们只能观测到两个潜在结果中的一个，另一个永远是未知的反事实

    因此，我们就需要算群体的平均：

    概念 含义
    ATE 总体平均处理效应 \(E[Y(1)] - E[Y(0)]\)：总体层面，"所有人都处理"与"所有人都不处理"相比的平均差异
    SATE 样本平均处理效应 \(\bar{Y}(1) - \bar{Y}(0)\)：样本层面，处理组平均值 − 对照组平均值
    • 这个差值能代表因果效应，前提是两组具有可比性：除了是否接受处理，其他方面平均而言都一样
    • 保证可比性的两种策略，就是本章的两大块内容

    2. 基于模型的推断¶

    课上用了一个模拟数据的情景：

    • 数据生成的设定：

      • 棕色头发使对数收入提高 0.1，这里收入用 log(income) 表示
      • 大学学历使对数收入提高 0.2
      • 如果上大学：则有 0.2 的概率是棕色头发，这是天生的棕色头发概率
      • 如果没上大学：则有 0.52 的概率是棕色头发，这是天生的棕色头发概率，加上染成棕色的概率

    • 实验目的：用统计模型把这个 0.1 的效应提取出来

    • 混淆的来源：

      • 没上大学的人中，有一部分会把头发染成棕色，所以发色就是和学历有相关性的
      • 原本的设定中，棕发对收入的直接影响是 0.1
      • 现在，棕发可以反映学历，而学历又影响收入，因此棕发还会通过学历对收入产生间接影响
      • 如果估计方法选择不当，我们估计的其实就是直接影响和间接影响混淆在一起的值，而不是单纯的直接影响

    课上我们对比了错误的朴素对比，以及两种正确做法的效果：

    方法 做法 结果 评价
    朴素对比 直接比较棕发组和非棕发组的平均收入 重复 1000 次平均约 0.045（棕发与非棕发的 log(income) 平均之差） 有系统性偏差，因为棕发组中没大学学历的人更多，把效应拉低了
    控制学历 只在有学历者中比较，不把学历不同的人混在一起 重复 1000 次平均约 0.103（有学历者群体里，棕发与非棕发的 log(income) 平均之差） 无偏，但只用了 30% 数据，导致波动大
    回归控制学历 将收入作为因变量，解释变量里同时放入棕发和学历 重复 1000 次平均约 0.100（棕发这个变量在回归中的系数） 无偏，用全部数据，因此波动更小，更精确

    这个案例的核心是：

    • 控制了混淆变量，就能还原出接近真实的效应；不控制混淆变量，朴素对比会得到有偏的结果

    • 但是这个方法的前提是：

      • 分析师知道混淆变量是什么
      • 数据里有这个变量，或者说混淆数据能收集到数据
      • 对关系的假设正确

    基于模型推断的局限：

    1. 未观测的混淆变量：数据里没记录的因素，模型无能为力
    2. 假设难以验证：模型假设是否对，通常无法从数据本身判断
    3. 模型结构错误：变量间的关系形式设错了，结论仍然会偏
    4. 最危险的是：错误悄无声息，分析者可能根本不知道有问题

    3. 基于设计的推断¶

    (1) 随机实验的概念¶

    随机对照实验 (RCT)，也叫 A/B 测试：随机决定每个个体进实验组还是对照组：

    • 随机分配使进哪个组与个体的所有其他特征都不相关
    • 所以两组在所有特征上平均而言相同，不管这些特征我们有没有观测到
    • 因此两组结果的差异，只能归因于处理本身

    例如我们课上举的例子是 DonorsChoose 的 A/B 测试，比较原文案和新文案的分享率和招募率：

    • 我们随机把用户分配到原文案组和新文案组，然后比较两组的分享率和招募率
    • 这样就能通过比较两组的结果，得到新文案的因果效应：对分享率有多大提高，对招募率有多大提高

    (2) 平衡性检验¶

    随机分配之后，要检查两组的实验前特征是否接近，验证随机化真的有效：

    • 看两组人数是否接近
    • 看实验前的特征的平均值是否接近

    在 DonorsChoose 的实验中，我们可以检查两组在实验前的特征是否接近，例如：

    • 用户的年龄、性别、地理位置、教育水平等
    • 用户的历史活跃度
    • 用户的过去的捐款次数
    • 文案推送的设备类型
    • 等等

    (3) 实验结果解读¶

    对于实验结果，我们有两种解读方式：绝对差异和相对差异，在 DonorsChoose 的实验中：

    分享率 招募率
    对照组（原文案） 14.4% 2.8%
    实验组（新文案） 15.1% 3.0%
    绝对差异 约 0.7 个百分点 （15.1% − 14.4%） 约 0.2 个百分点 （3.0% − 2.8%）
    相对差异 约 5% （(15.1 − 14.4) ÷ 14.4） 约 8% （(3.0 − 2.8) ÷ 2.8）
    • 绝对差异：两个百分比相减
    • 相对差异：差异除以对照组的值
    • 虽然单位都是百分号，但是大家要注意这两种算法的差异

    (4) 随机实验的假设¶

    随机实验的有效性依赖以下假设：

    类别 假设 含义 违反的例子
    可比性 随机化按预期执行 每人被分配到各组的概率相同 程序 bug 让更活跃的捐赠人被分到了同一组
    处理是唯一的差异 两组之间只有处理不同 同时改了文案和弹窗布局
    遵从分配 人们实际收到了被分配的版本 实验组部分人其实没看到新文案（不合规）
    稳定性 无干扰 一个人的结果只取决于自己的处理 实验组用户公开分享，被对照组看到（溢出效应）
    无选择性损耗 被分配的人都能产生可观测的结果 某组很多人没到达分享页面
    处理的一致性 同组的人收到的处理完全一样 不同浏览器显示略有不同的文案

    4. 两种核心策略的对比¶

    基于模型的推断 Model-based 基于设计的推断 Design-based
    方法 用统计模型控制混淆变量 通过随机分配设计实验
    依据 对数据生成过程的假设 数据是如何收集的（随机分配机制）
    可观测的混淆变量 通过控制来处理 随机化天然平衡
    未观测的混淆变量 无法处理，结论会悄悄出错 随机化天然平衡
    假设能否验证 通常难以从数据本身验证 可以用平衡性检验直接检验
    适合 做不了实验时的替代方案 可以用实验来收集数据的场景
