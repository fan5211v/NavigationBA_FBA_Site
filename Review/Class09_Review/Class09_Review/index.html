    Class 9 知识点总结¶

    Class 9 是预测分析本章的核心是四种预测方法，以及三个误差指标：

    • 预测的基本概念：预测分析的重要原则，以及训练集&测试集的概念
    • 四预测方法：一期滞后、移动平均、历史累计均值、线性回归
    • 三个误差指标：MAE、RMSE、MAPE

    1. 预测分析的基本概念¶

    (1) 预测分析的原则¶

    预测分析的概念我们在 Class 1 已经提过了：

    • 简单来说就是预测未来会发生什么
    • 和描述性分析、因果分析的差别也很明显，我们这里就不再赘述
    • 预测分析的重要性在于指导商业决策，帮助企业在不确定的未来做出更合理的规划，课上举的例子是，我们预测下一场球赛的上座人数，从而为赛场安排合适的人员和资源

    预测分析的一个最重要的原则是：只能使用预测那一刻已经知道的信息，不能使用未来的信息：

    • 比方说我们之前见过的股票的例子：
    | date       | price | volume | turn |
|------------|-------|--------|------|
| 2024-01-01 | 100   | 500    | 0.1  |
| 2024-01-02 | 105   | 520    | 0.12 |
| 2024-01-03 | 102   | 510    | 0.11 |
| 2024-01-04 | 108   | 530    | 0.13 |
| 2024-01-05 | 112   | 540    | 0.14 |
    • 当我们预测某一天的股票价格时，只能使用那一天之前的数据，不能使用当天或之后的数据
    • 这就是我们在将时间序列数据时和大家强调，基本上我们在时间序列中不会向后取数据，也就是 lead() 函数基本很少用
    • 因为会导致未来信息（future information）泄露，破坏预测分析的原则，导致前视偏差 (look-ahead bias)

    (2) 训练集 & 测试集¶

    在预测分析中，我们通常会把数据按照时间来分为训练集和测试集：

    • 训练集（Training set）：用来训练模型，学习数据的规律
    • 测试集（Test set）：用来评估模型的预测能力，模拟对未来的预测

    通常来说，划分依据就是时间先后，例如我的数据区间是 2024-2026：

    • 训练集就可以使用 2024-2025 年的数据
    • 测试集就可以使用 2026 年的数据
    • 通常来说比例是不固定的，但是通常训练集要比测试集大，保证模型有足够的数据学习规律

    分测试集与训练集：

    • 核心思想在于：

      • 训练集相当于是让模型学习历史数据中的规律
      • 测试集相当于是检查模型学到的这个规律，在新的、未见过的数据上是否仍然有效
      • 也就是说，模型表现如何，我们并不是在训练集上看，而是在测试集上看，才能真实反映模型对未来的预测能力

    • 一个通俗的例子就是：

      • 训练集就像学生平时的练习题，用来学习和掌握知识
      • 测试集就像期末考试，用来检验学生是否真正掌握了知识
      • 学生真正学没学会只是，不是平时作业说了算的，而是期末考试的成绩才说明问题

    2. 预测方法¶

    (1) 时间序列方法¶

    我们课上一共介绍了四种方法，前三种都是简单的 时间序列方法：

    • 一期滞后（Lag 1）：用上一期的值作为预测：
    \[\widehat{Y}_{t+1} = Y_{t}\]
    • 三期移动平均（Trailing average）：用最近三期的平均值作为预测：
    \[\widehat{Y}_{t+1} = \frac{1}{3}(Y_{t} + Y_{t-1} + Y_{t-2})\]
    • 历史累计均值（Historical mean）：用从第一期到上一期的平均值作为预测：
    \[\widehat{Y}_{t+1} = \frac{1}{t}\sum_{i=1}^{t} Y_i\]

    我们用一个简单的例子来看一下前三种方法的预测效果：

    price_stock <- tibble(

    price = c(100, 105, 102, 108, 112, 115, 118, 120, 125)
)

    (2) 线性回归方法¶

    第四种，线性回归模型（Linear regression），是使用其他变量预测目标变量：

    \[\widehat{Y}_{t+1} = \widehat{\beta}_0 + \widehat{\beta}_1 X_{1,t} + \widehat{\beta}_2 X_{2,t} + \cdots + \widehat{\beta}_k X_{k,t}\]
    • 其中，我们使用的预测变量，也叫特征变量，是用来帮助预测目标变量的其他信息

    • 例如，我们要预测股票价格 \(Y_{t+1} = Price_{t+1}\)：

      • 可以使用上一期的其他信息作为特征变量，例如：

        • 上一期的成交量 \(X_{1,t} = Volume_t\)
        • 上一期的市场指数 \(X_{2,t} = Index_t\)
        • 上一期的宏观经济指标 \(X_{3,t} = Macro_t\)

      • 也可以使用更多期之前的特征变量，例如：

        • 前两期的成交量 \(X_{4,t-1} = Volume_{t-1}\)
        • 前两期的市场指数 \(X_{5,t-1} = Index_{t-1}\)
        • 前两期的宏观经济指标 \(X_{6,t-1} = Macro_{t-1}\)

      • 也可以使用上一期或者更多期之前的目标变量本身：

        • 上一期的目标变量 \(X_{7,t} = Y_t = Price_t\)
        • 前两期的目标变量 \(X_{8,t-1} = Y_{t-1} = Price_{t-1}\)

    • 总而言之一句话，预测 \(t+1\) 期的目标变量时，可以使用任意 \(t\) 期及更早的特征变量和目标变量的历史值，只要不使用未来信息就可以

    线性回归的代码就是 lm()，例如：

    set.seed(2024)

n <- 20

price_stock_new <- tibble(
    date   = seq(as.Date("2024-01-01"), by = "day", length.out = n),
    macro  = round(1.5  + rnorm(n, 0, 0.05), 4),
    index  = round(3000 + rnorm(n, 0, 40)),
    volume = round(1200 + rnorm(n, 0, 150)),
    price  = round(100  + rnorm(n, 0, 1.5), 2)
    ) |> 
    mutate(
        macro_lag1  = lag(macro, 1),
        index_lag1  = lag(index, 1),
        volume_lag1 = lag(volume, 1),
        price_lag1  = lag(price, 1),
        price_lag2  = lag(price, 2)
    ) |>
    arrange(date)

    3. 误差指标¶

    (1) 预测误差¶

    预测误差是每个样本的实际值与预测值之差：

    \[e_t = Y_t - \widehat{Y}_t \quad (\text{实际值} - \text{预测值})\]
    • 预测误差是每一个样本都有一个误差
    • 例如 2024-01-08 这一天的实际价格是 1400，预测值是 1300，那么预测误差就是 1400 - 1300 = 100

    (2) 三个常用误差指标¶

    预测误差是每个样本都有的，而误差指标是要将这些误差汇总成一个数，用来衡量整体预测的准确性：

    • MAE 平均绝对误差：

      • 公式：\(\frac{1}{T}\sum \lvert e_t\rvert\)
      • R 代码：mean(abs(actual - pred), na.rm = TRUE)
      • 单位：与变量相同
      • 特点：所有误差权重相同，最直观，直接反映每个样本平均的预测误差为多少

    • RMSE 均方根误差：

      • 公式：\(\sqrt{\frac{1}{T}\sum e_t^2}\)
      • R 代码：sqrt(mean((actual - pred)^2, na.rm = TRUE))
      • 单位：与变量相同
      • 特点：更重视大误差

    • MAPE 平均绝对百分比误差：

      • 公式：\(\frac{1}{T}\sum \left\lvert \frac{e_t}{A_t}\right\rvert\times 100\%\)
      • R 代码：mean(abs((actual - pred) / actual)) * 100
      • 单位：百分比，无单位
      • 特点：方便比较不同规模的场景，但是在实际值接近 0 时会得到异常大的值

    我们通过一个例子来计算这三个指标，看看它们的差异：

    | date       | price | pred_lag1 | error | data_set |
|------------|-------|-----------|-------|----------|
| 2024-01-01 | 100   | NA        | NA    | train    |
| 2024-01-02 | 105   | 100       | 5     | train    |
| 2024-01-03 | 102   | 105       | -3    | train    |
| 2024-01-04 | 108   | 102       | 6     | train    |
| 2024-01-05 | 112   | 108       | 4     | train    |
| 2024-01-06 | 115   | 112       | 3     | train    |
| 2024-01-07 | 118   | 115       | 3     | test     |
| 2024-01-08 | 120   | 118       | 2     | test     |
| 2024-01-09 | 125   | 120       | 5     | test     |
    • MAE：
    - 训练集：(5+3+6+4+3) / 5 = 21 / 5 = 4.2
- 测试集：(3+2+5) / 3 = 10 / 3 = 3.33
- 全样本：(5+3+6+4+3+3+2+5) / 8 = 31 / 8 = 3.875
    • RMSE：
    - 训练集：((5²+3²+6²+4²+3²) / 5) ^ (1/2) = ((25+9+36+16+9) / 5) ^ (1/2) = (95 / 5) ^ (1/2) = 19 ^ (1/2) = 4.36
- 测试集：((3²+2²+5²) / 3) ^ (1/2) = ((9+4+25) / 3) ^ (1/2) = (38 / 3) ^ (1/2) = 12.67 ^ (1/2) = 3.56
- 全样本：((5²+3²+6²+4²+3²+3²+2²+5²) / 8) ^ (1/2) = ((25+9+36+16+9+9+4+25) / 8) ^ (1/2) = (133 / 8) ^ (1/2) = 16.625 ^ (1/2) = 4.08
    • MAPE：
    - 训练集：((5/105 + 3/102 + 6/108 + 4/112 + 3/115) / 5) * 100 = ((0.0476 + 0.0294 + 0.0556 + 0.0357 + 0.0261) / 5) * 100 = (0.1944 / 5) * 100 = 0.03888 * 100 = 3.89%
- 测试集：((3/118 + 2/120 + 5/125) / 3) * 100 = ((0.0254 + 0.0167 + 0.0400) / 3) * 100 = (0.0821 / 3) * 100 = 0.02737 * 100 = 2.74%
- 全样本：((5/105 + 3/102 + 6/108 + 4/112 + 3/115 + 3/118 + 2/120 + 5/125) / 8) * 100 = ((0.0476 + 0.0294 + 0.0556 + 0.0357 + 0.0261 + 0.0254 + 0.0167 + 0.0400) / 8) * 100 = (0.2765 / 8) * 100 = 0.03456 * 100 = 3.46%

    计算的时候要注意以下几点：

    • NA 值在计算的时候要排除，因此上面这个例子中，训练集看似是 6 个样本，实际上只有 5 个有效样本
    • 在计算的时候一定要看清题目要求是训练集、测试集、还是全样本，不要混淆
    • 真正能评价模型预测能力的，是在测试集上的表现，而不是训练集，也不是全样本

    (3) 模型比较的原则¶

    模型在比较时，应该注意以下几点：

    • 首先，我们要看的应该是测试集上的表现，因为测试集能够反映模型在未见数据上的预测能力

    • 其次，三个指标可能会给出不同的评价结果，比方说看 MAE 可能是 A 模型好，但是看 RMSE 可能是 B 模型更优，因此：

      • 我们先看题目要求的指标，明确是要比较 MAE、RMSE 还是 MAPE
      • 如果题目没有明确要求某个指标，我们就把三个指标都计算出来，说根据每个指标哪个模型最优即可
