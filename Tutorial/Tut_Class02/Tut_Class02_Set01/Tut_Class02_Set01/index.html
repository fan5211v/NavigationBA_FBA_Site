    Tutorial Class 02 Set 01 - From Data to a Managerial Briefing¶

    Learning Goals¶

    By the end of this tutorial, you should be able to:

    • Explain what Quarto is and why analysts use it
    • Run R code inside a .qmd file and render a report
    • Load a small dataset and compute a few inventory KPIs
    • Produce a simple table and a basic plot
    • Write a manager-friendly recommendation that separates facts vs interpretation vs decision

    The Business Challenge¶

    David Jones sells a wide range of seasonal products, including fashion items that see strong swings in demand around holidays like Christmas.

    Inventory decisions are especially challenging for seasonal products because:

    • Demand can spike unpredictably
    • Promotions and discounts influence customer behaviour
    • Regional preferences can differ
    • Suppliers need advance notice to adjust deliveries

    Right now, David Jones is using a fixed restocking rule: Every week, 100 units are delivered to each region, no matter what.

    But with the holiday season approaching, this rigid approach might not be enough.

    Management wants a one-page briefing outlining whether they should adapt their restocking rule.

    Your task is to review last year’s data and advise David Jones on how to improve inventory decisions.

    Prepare these Exercises before Class¶

    Prepare these exercises before coming to class. Plan to spend 45 minutes on these exercises.

    Exercise 1: Approaches to Inventory Planning¶

    Read the article, “A New Approach to Production and Inventory Planning,” and answer the following questions in 2–3 sentences:

    1. Define the term “inventory management”. What makes inventory management complicated for seasonal products?
    2. What is one key challenge businesses face in managing inventory today?
    3. How could this apply to a retailer like David Jones, especially during busy seasons like Christmas?

    Solution

    1. Inventory Management is the process of planning, tracking, and controlling stock so that a business can meet customer demand without holding excess or running out.

      • For David Jones, the challenge stems from when demand for gift hampers can spike quickly — poor planning could mean lost sales, unhappy customers, or leftover stock that must be heavily discounted.

      • Extra info: There are three key techniques in inventory management:

        • Economic Order Quantity (EOQ): A formula used to determine the optimal quantity to order that minimises total inventory costs — including both ordering costs and holding costs. Think of EOQ as the sweet spot: not too frequent, not too much.

        • Safety Stock: Extra buffer stock kept on hand to prevent stockouts due to unexpected spikes in demand or delays in delivery. It’s like a “just-in-case” cushion for uncertainty.

        • Reorder Point: The inventory level at which a new order should be placed so stock arrives before you run out. It accounts for delivery lead time + expected demand.

    2. One key challenge is balancing efficiency with flexibility. Many traditional inventory systems aim to minimise costs by keeping stock levels low (like with just-in-time models), but these systems struggle when there is uncertainty or sudden changes in demand. This makes businesses vulnerable to stockouts or delays when things don’t go as planned.

    3. David Jones experiences unpredictable demand spikes during the holiday season. If they rely on a rigid or overly efficient inventory rule, they risk running out of popular items like gift hampers or over-ordering and being left with excess stock. To avoid this, they need a more flexible approach that can adjust to regional sales trends, promotion effects, and delivery timing issues.

    Exercise 4: R + Quarto Vocabulary Check (5 Quick Definitions)¶

    Answer each in one short sentence.

    • What does <- do in R?

    • What is a data frame (and what does a row represent in our David Jones data)?

    • What is a function in R? Give one example.

    • What is a code chunk in a Quarto .qmd file?

    • What does Render do in Quarto?

    Solution

    • What does <- do in R? It assigns the value on the right to the object name on the left (e.g., x <- 5 stores 5 in x).

    • What is a data frame (and what does a row represent in our David Jones data)? A data frame is a table with rows and columns; here, one row represents one region-week observation (e.g., Sydney in the week commencing 2 Dec).

    • What is a function in R? Give one example. A function is a command that takes inputs and returns an output (e.g., sum(x), mean(x), min(x)).

    • What is a code chunk in a Quarto .qmd file? A code chunk is a block where you write R code that Quarto runs when rendering, and it shows the results (numbers/tables/plots) in the output.

    • What does Render do in Quarto? Render runs all code chunks and converts the .qmd into an output document (e.g., HTML/PDF) with the results inserted.

    • Do you need to change the #| eval: false setting to run the code when you render the file? - Yes. To load the dataset during rendering, you must remove it or change it (e.g., to #| eval: true) so the chunk executes.

    (d) Inspect commands (what they return / how to interpret them)**

    • names(inventory) - Lists the column names (variable names) in the dataset.
    • head(inventory) - Shows the first few rows so you can sanity-check that the data imported correctly.
    • nrow(inventory) - Returns the number of rows (how many observations).
    • ncol(inventory) - Returns the number of columns (how many variables).

    Exercise 8: Turning Numbers into a Story (Before We Recommend Anything)¶

    You’ve just computed a few KPIs in R (revenue, units sold, minimum ending inventory, and whether backorders occurred).

    Before we jump to “what should David Jones order?”, we need to answer a more basic question: What do the numbers actually tell us — and what do they not tell us?

    (a) What are the two most important facts you learned from your KPIs?

    Write them as two short bullet points (each should reference a KPI you computed).

    (b) Based on those facts, what is your group’s best guess about what will happen next week if David Jones keeps doing the same thing?

    (c) What is one caveat you would tell management about your answer to (b)?

    Solution

    There isn’t a single “correct” set of sentences. A good answer uses the group’s computed KPIs and stays disciplined about what the data can (and can’t) support.

    (a) Two most important facts (examples of strong answers) - Accept any two that reference computed KPIs clearly, for example:

    • Fact (demand/value): Melbourne generated higher total units sold / revenue than Sydney over these weeks.
    • Fact (risk): Inventory risk is higher in Melbourne: it has the lowest ending inventory, and there is at least one backorder (ending inventory < 0).
    • Fact (timing spike): The Christmas promo week coincides with the largest jump in units sold and a sharp drop in ending inventory in both regions.

    (b) Best guess for next week if nothing changes (examples) - A strong answer is predictive but conditional, e.g.:

    • If David Jones keeps delivering 100 units and demand stays similar, Melbourne is likely to stock out / backorder again, while Sydney is less likely to (but could still run low).
    • Expect higher risk in Melbourne because its sales appear higher and its ending inventory hit the lowest/negative values.

    (c) One caveat to tell management (examples) - Good caveats point to a specific limitation:

    • We don’t know when deliveries arrive relative to sales within the week, which affects the interpretation of “ending inventory risk.”
    • The dataset is small (few weeks), so forecasts are uncertain and sensitive to assumptions.

    Exercise 9: Planning for This Year’s Holiday Season¶

    David Jones’ supplier is asking you to confirm delivery quantities now, so they can prepare for the season ahead.

    1. How many units should you order for Sydney and Melbourne for the first week of the holiday season?
    2. Justify your decision based on last year’s patterns and your reasoning. Consider factors like demand trends, regional differences, price effects, and promotion timing.
    3. Suppose the supplier has limited capacity and can only supply 200 units total for the first week. How would you allocate this stock between Sydney and Melbourne? What are the risks of your choice?

    Solution

    Unconstrained scenario:

    Based on last year’s sales in the first week of the season (25 Nov), Melbourne sold 150 units while Sydney sold 100. Given this pattern and assuming similar demand and pricing this year, we recommend ordering:

    • Melbourne: 150 units
    • Sydney: 100 units

    This matches observed demand and adjusts the previous fixed rule to better reflect regional differences.

    Constrained Scenario:

    Based on last year’s Week 1 sales (25 Nov), Melbourne sold 150 units and Sydney sold 100 — a 60:40 demand split. Assuming similar demand patterns this year, we propose the following allocation:

    • Melbourne: 120 units
    • Sydney: 80 units

    This proportional allocation preserves observed demand ratios while fitting within the 200-unit constraint.

    Assumptions:

    • We assume last year’s demand is a reasonable guide for this year.
    • We assume supply constraints are fixed and inflexible (i.e. we can’t reorder mid-season).
    • We assume there are no major regional marketing changes this year (e.g. no extra advertising / price changes).

    Risks:

    • If demand increases (e.g. due to earlier or stronger promotions), understocking is likely.
    • If regional patterns shift, the proportional rule may misallocate units — e.g. underestimating growth in Sydney.
    • Without real-time data, it’s hard to adjust — we’d ideally revisit this weekly.

    Data reasoning: Our decision uses descriptive analysis (last year’s observed sales), predictive reasoning (similar patterns expected), and light causal inference (we infer regional differences reflect customer demand, not supply issues).
